1 — the same URL, three ways

You sendYou get
curl https://HOST/pkgthe manifest (machine surface)
a browser visit to https://HOST/pkgthe card page (human surface)
paste https://HOST/pkg into X / Discord / Slackthe unfurl (crawler surface — OG + twitter:card)

2 — try it from your terminal

# the machine surface (an agent's view)
curl -A "curl/8.4" https://HOST/simple-package

# the human surface
open https://HOST/simple-package

# the crawler surface (what X/Discord fetch)
curl -A "Twitterbot/1.0" https://HOST/simple-package | head -20

3 — the one-liner, live

Read https://HOST/simple-package/INGEST.md and execute its load order; it routes everything else.

Your agent fetches the manifest, executes the load order, and the whole package routes from one line. That is the entire convention.

4 — arm your own

git clone https://github.com/MediaPlural/ingest
cd ingest
python3 ingest.py init ./my-package --bluf bluf.txt
python3 tools/arm.py ./my-package --slug my-package --url https://HOST/my-package

The arming tool copies the artifact set into the host's packages/ dir and stamps the share URL. The manifest stays the single source of truth.
